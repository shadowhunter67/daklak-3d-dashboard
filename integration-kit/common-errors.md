# Common errors — ví dụ cụ thể

| Lỗi                                   | Ví dụ input sai                                                                                          | Sửa thế nào                                                                                                                      |
| ------------------------------------- | -------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Sai encoding                          | File lưu bằng Excel "CSV (Comma delimited)" mặc định trên Windows (thường ANSI/Windows-1258)             | Lưu lại bằng "CSV UTF-8 (Comma delimited)"                                                                                       |
| Header thiếu                          | Thiếu cột `approved_budget_vnd` trong `projects.csv`                                                     | Thêm đúng cột canonical, xem `data-templates/csv/projects.csv`                                                                   |
| Header lặp                            | Hai cột cùng tên `status`                                                                                | Đổi tên/xoá cột trùng                                                                                                            |
| Ngày mơ hồ                            | `01/02/2026` (không rõ là 1/2 hay 2/1)                                                                   | Dùng `2026-02-01` (ISO, luôn `YYYY-MM-DD`)                                                                                       |
| Số tiền có dấu phân cách              | `1,000,000,000` hoặc `1.000.000.000`                                                                     | Ghi số nguyên thuần: `1000000000`                                                                                                |
| Mã hành chính không tồn tại           | `24999` (không có trong `daklak-labels.json`)                                                            | Tra lại mã đúng theo Nghị quyết 1660/NQ-UBTVQH15 sau sáp nhập 2025                                                               |
| Foreign key hỏng                      | `work-packages.csv` có `project_id=prj-999` nhưng `projects.csv` không có `prj-999`                      | Thêm project đó vào `projects.csv`, hoặc sửa lại `project_id`                                                                    |
| Duplicate ID                          | Hai dòng cùng `id=prj-001` trong `projects.csv`                                                          | Đổi id cho một trong hai, đảm bảo mỗi id chỉ xuất hiện một lần                                                                   |
| Duplicate progress identity           | Hai dòng `progress-snapshots.csv` cùng `project_id`+`observed_at`+`source_dataset_id`+`source_record_id` | Nếu là cùng một lần ghi trùng lặp thật, xoá bớt; nếu là 2 giai đoạn xác thực khác nhau, đổi `source_record_id` cho mỗi giai đoạn |
| Missing sourceDatasetId               | Thiếu `source_dataset_id` ở `projects.csv` (field bắt buộc)                                              | Điền dataset id đã đăng ký trong `DATASET_CATALOG`, hoặc khai báo qua `--source-registry`                                        |
| Unsupported schema version            | Bundle JSON có `"schemaVersion": "2.0.0"` khi importer chỉ hỗ trợ `1.0.0`                                | Kiểm tra lại nguồn bundle — có thể là bundle từ một phiên bản importer khác                                                      |
| Approximate geometry thiếu disclaimer | `geometryMetadata.approximate: true` nhưng không có `legalStatusDisclaimer`                              | Thêm câu disclaimer (vd "Vị trí minh hoạ gần đúng — chưa khảo sát chính thức")                                                   |
